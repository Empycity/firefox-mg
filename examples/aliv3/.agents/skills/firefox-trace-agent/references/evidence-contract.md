# Evidence Contract

## Request sink record

```text
trace_dir
manifest path/hash
request file/line
request_id
transport/method/url
field location/name: url.query | body | headers | cookies
field raw SHA-256
field decoded SHA-256
field value_store_path
origin_call_id
segment_id/control_version/config_hash
trace health
```

## Producer match record

```text
js file/line
call_id
parent_call_id
origin_call_id
function_name
script_url
script_sha256
value role/path
value SHA-256
value_store_path
match kind: exact-value | sha256 | decoded_sha256 | segment_sha256
producer_match selection: same pid/segment, before request, exact return, deepest parent chain
producer_chain: ordered producer call -> parent calls
```

Producer evidence needs value identity plus execution/request context.
An `origin_call_id` that identifies only a transport wrapper is not a producer
gap when an exact request-value SHA resolves to a retained JS return chain.

## Environment/state dependency record

```text
dependency_id
class: environment | state | mixed
source kind: BOM | DOM | cookie | storage | response | time | random | crypto
source event file/line/type/member
source value SHA-256 or preview
propagation_call_ids

```

## A/B validity

A valid A/B pair changes one modeled input and keeps target action, business inputs, browser build, script identity, filters, and trace health comparable. Compare source value, producer value, and request field in both runs.

## Pure-compute contract

```text
function name/version
output field and encoding
explicit inputs with types
normalization
serialization/order/escaping
crypto/hash primitive
output assembly
test vectors with browser trace refs
```

Browser API and state acquisition stay outside the pure function.

## Reproduction gate

Reproduction proceeds in two gates:

1. Fixed-vector gate: URL, headers, cookies and body bytes match the trace vector at diff level.
2. Dynamic gate: dynamic values are generated by the original SDK/supplemented runtime or by a pure function with confirmed inputs, then the user-provided URL returns the expected response status/content/business success condition.
