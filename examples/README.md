# Verified Examples

The directories here are self-contained, site-specific validation cases. They
are not loaded by the Firefox Trace Console or its generic analysis workflow.

- `douyin/`: creator upload-to-publish capture, local `a_bogus` generation, and Firefox replay.
- `jd-h5st-dynamic/`: dynamic JD `h5st` request generator.
- `jd-h5st-full-test/`: verified JD `h5st` pure-compute and environment-assisted flows.
- `globalsources-reese84/`: Global Sources rly/`p` trace, environment probe, and byte-alignment diagnostics.

Run each example from the repository root using the command in its README.
